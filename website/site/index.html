−18 m连接

一根直连的光纤，
中间没有任何中转站。

手机直接与你的 OpenCode 服务端建立连接：REST 读写加上全局 SSE 事件流。 v0.2.0 起已彻底移除 FCM 推送与伴随服务，凭据只留在你自己的手机里。

点按任一服务器节点，切换当前服务器。

  • 直连端点填写服务器地址，或直接粘贴 opencode pair 输出的官方配对链接（强制 HTTPS）。
  • Keystore 加密密码与会话 Cookie 由 Android Keystore AES-GCM 保护；请求绑定固定 origin，禁止跨源重定向转发凭据。
  • 断线自动对账SSE 断开后自动重连，并重新读取控制状态补齐断线期间的变化。
  • 明文需显式授权建议走 HTTPS 或可信 VPN；局域网 HTTP 必须在该服务器资料中明确开启。

−46 m会话

离开电脑，
对话不必中断。

时间线按官方客户端规则投影：轮次分组、工具折叠、只显示最后一条错误。下滑看看一次任务在 Lagoon 里如何展开。

  1. 01

    在手机上下达任务

    选择项目、Agent 与模型，输入任务或斜杠命令（经服务端 /command 执行），也可以附上图片和文件。

  2. 02

    过程收成一条轨迹

    每个用户轮次的工具调用收拢为「共处理 N 个操作」。展开即可查看命令与输出、读写路径、编辑前后文本与思考过程。

  3. 03

    授权与提问，就地处理

    Agent 需要执行关键动作时，直接在手机上「允许一次」或「拒绝」；只有服务端给出保存范围时才提供「始终允许」。问答表单同样可以直接填写。

  4. 04

    运行中，也能继续引导

    任务运行时仍可继续发送消息来引导当前轮次，或随时停止。消息由客户端生成 id，断线时只用同一 id 重试一次。

  5. 05

    子会话、改动与文件

    右上角 ⋯ 收纳子任务、代码改动与文件浏览搜索；重命名、置顶、删除都在手边。

−80 m实时更新

像生物荧光一样，
状态会自己亮起来。

Android 16 上，服务器总览以系统「实时更新」常驻状态栏胶囊与锁屏，只在有任务运行或待处理时上岛。 外观完全交给系统绘制，Lagoon 只按标准格式提供内容，不写任何厂商私有字段。

    需要中转服务器或推送服务吗？

    不需要。手机直接连接你的 OpenCode 服务端；自 v0.2.0 起已移除 FCM 与伴随服务，后台通知由本机前台服务监听事件流后在本地发出。

    支持 OpenCode 1.x 或其他 harness 吗？

    目前只支持 OpenCode 2.x（1.x 已不再支持）。适配更多 coding agent harness 是规划方向，尚无承诺的发布时间。

    我的凭据和数据存在哪里？

    服务器密码与会话 Cookie 经 Android Keystore 加密保存在手机上；离线缓存同样加密存放在本机。除你自己配置的服务器外，Lagoon 没有任何云端服务接收这些数据。

    为什么有时收不到后台通知？

    Android 会限制后台运行：强行停止应用、系统清理以及 Android 15+ 对 dataSync 前台服务的时长限制都可能中断监听。Lagoon 会在回到前台或定时任务时重新对账，但不承诺无限后台保活。

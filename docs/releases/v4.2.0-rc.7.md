## 本次更新

- **修复 DSH Remote 打开部分会话时报“Remote 流数量超过上限”**：每台 Host 的 16 条逻辑流预算原先会被首页刷新和后台流占满，导致较旧会话无法打开。现在长期 `session/follow` 严格限制在 12 条，首页只为运行中的会话开 follow，当前阅读的会话固定保留。
- **修正 follow 的淘汰顺序**：按最近活跃时间淘汰，不再出现“保留最旧 12 个会话、却给所有会话开流”的错位；取消时同步归还网关槽位，新流不必等旧协程调度结束。
- **后台流不再挤占核心流**：`job/list` 最多同时 2 条，`job/follow` 保持 1 条；网关硬上限从 16 提升到 32，仅作兜底。达到上限时会释放一条非当前会话的旧 follow 后重试一次。
- **断线重连更克制**：follow 意外断开后只重连仍在观察集合里的会话，历史会话的流不会被反复复活。
- **连接医生新增“流预算”**：显示当前占用/上限、按 endpoint 的计数和最近一次流错误，便于继续定位 Host 侧或客户端流异常。
- **回归测试**：新增首页只关注运行中会话、20 会话 follow 上限、当前会话固定、后台流压力、`closeNow` 同步释放与网关硬上限测试。

## 已知限制

- 本机未连接真实 DSH Host 或 Android 真机；尚未在 20+ 会话的真实 Host 上验收“打开最旧会话 + 首页刷新 + 后台 shell 输出”的组合场景。
- 若 Host 侧仍有独立限制或某条流卡在传输分片，连接医生的 endpoint 计数与最近流错误可用于继续定位。
- 预发布版本使用与正式版相同的稳定签名；覆盖安装前请确认与已安装版本签名一致。

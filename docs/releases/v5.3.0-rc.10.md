## 本次更新

- **首页下拉刷新不再冻结列表**：用自定义下拉刷新容器替换 MIUIX `PullToRefresh`，刷新期间列表仍然可以正常上下滚动；刷新开始和结束都会回到顶部。同步提示里的“重试”和空状态里的“重新连接”也走同一个刷新入口。
- **Remote 主机支持本地显示名**：中枢 Host 自报名称为空或全 `?` 时不再直接显示 `???`，回退为“未命名主机”；主机行新增“命名”入口，可为这台设备设置只影响本机的显示名。刷新或重新接入时保留已有本地名称，Host 新报名不可读时也保留上一个可读名称。
- **统一 Remote 设备显示名**：连接图投影、`ServerProfile.name` 和客户端注册名都使用本地显示名；显示名只影响界面，不改变指纹、凭据、路由或会话身份。
- **修复 Windows 工作站的 Host 自报名称**：Windows DSH 远程插件已写入 `deviceName: 工作站`，Host 身份文件和中枢目录中的名称已恢复为“工作站”；后续重新注册会继续上报正确名称。

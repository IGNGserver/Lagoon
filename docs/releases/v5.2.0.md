## 本次更新

- **交互与信息架构收敛**：
  - 设备详情独占设备级配置（默认模型、连接方式、远程与 SSH），全局设置只保留跨设备偏好，「添加设备」改为带返回手势的独立全屏流程，不再以嵌套半屏抽屉出现。
  - 聊天页「停止生成」在运行各阶段始终独立可见；权限与问答统一收敛到「待你处理 · N 项」聚合面板，修复关闭二级确认框后外层面板误判为可关闭的问题。
  - 删除、清空、退出等危险操作统一为二次确认，并明确说明影响范围。
- **组件与可读性统一**：
  - 主/次/三级/危险按钮、文字动作、圆形图标按钮、卡片、开关与分段控件统一尺寸与语义：可点击入口补足 48dp 触控目标，圆形视觉统一 40dp，加载中保留按钮文案并阻止重复提交。
  - 明确区分「向右进入下一级」「向下展开选择」「旋转表示展开/收起」与表示选中的对勾，修正设备管理、添加设备、首页分组等处的箭头方向。
  - 深浅色四级表面与「信息 / 成功 / 警告 / 错误」语义提示重新取值，新增 WCAG 对比度回归测试，正文与语义提示在画布和卡片两类背景上均达到 4.5:1。
- **凭据与明文连接边界**：
  - SSH 密钥改为留空即保留原值、输入即替换、需显式确认才可清除，已保存的秘密不再回显到表单；高级选项默认收起。
  - HTTP 明文授权与精确地址绑定：修改服务器地址会立即撤销原授权，解析或粘贴链接不再推断授权；旧版远程目录默认按未授权处理，需重新登录并显式允许。
  - 旧 HTTP 远程账号不再静默刷新失败，改为展示原因并提供「重新登录并授权」入口。
- **表单与列表减负**：
  - 模型目录支持搜索过滤并按服务商语义展示；工作区、设备分组、远程与 SSH 表单统一排版，移除前端无需展示的底层字段。
  - 首页、会话列表与转录区统一操作入口，补齐自定义可点击行（活动摘要、分组折叠头、草稿服务器行）的触控高度。

## 本次更新

- **配对与添加后自动探测挂载**：扫码配对（Scan-to-Pair）与 Hub 登录接入设备后自动执行探测（probe）、自动挂载并启用连接；支持 Hub 目录与扫码配对目录独立共存，接入异常时保留已有 `accountToken`；修复明文（cleartext）策略判定顺序及 `host:port`（含 IPv6、IDN/Punycode）解析问题。
- **删除设备与 Harness 彻底清理**：删除设备或 Harness 时同步移除设备记录、加密身份槽、`ServerProfile` 投影并驱逐活跃连接缓存；`RemotePeerTrustStore` 改为原子确认/替换/移除与槽位擦除；新增防复活投影屏障、加密持久化异步服务端吊销队列（`PendingRemoteRevocation`）与返回栈守卫。
- **中文/Unicode/Emoji 与局域网域名兼容**：修复中文与多语言设备名校验与展示、Emoji 代理对（surrogate pair）安全截断、IDN/Punycode 域名、`.local` 及含下划线主机名、UTF-8 Basic Auth 编码、URL 查询参数编码及 `nextCursor` 分页游标。
- **原生 Stock AGY 与 OpenCode ACP 多后端支持**：在不升级连接图存储版本（`ConnectionGraphCodec.VERSION = 1`）的前提下支持 `OPENCODE_ACP`，补齐 `agent.acp.*` 多后端帧过滤、全局会话列表（`limit = 500`）、`opencode:<sessionId>` 工作区文件作用域与路由槽位隔离。
- **对齐官方 `ds-harness-remote` v0.6.5+ 协议与流预算防护**：支持 `DSHUP` 二进制分块工作区上传（`binary-v1`）与 Relay `20 MiB` 上限、Remote 附件 `fileUploads/upload` 优先回退、`compactSessionAsync` 异步压缩、Relay `harness.api.v1` 能力与数据通道 `ping/pong`/关闭码语义；同时针对 16 条流上限收敛 Remote 并发流预算（`job/follow` 限制并发、`session/follow` 上限收敛为 8，`workspace/follow`/`$events` 遇限流自动驱逐后台 follow 重试），防止核心流饥饿。

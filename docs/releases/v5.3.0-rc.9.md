## 本次更新

- **远程中枢重新登录与凭据自动恢复**：远程中枢退出或登录态失效后重新登录同一中枢时，区分用户主动暂停与登录失效状态并自动恢复被停用的中枢接入源（`ConnectionSource.enabled`）；同步将中枢目录中已固定（`PINNED`）主机的服务端公钥指纹（`remoteHostFingerprint`）与明文传输策略（`allowCleartext`）写回本地 `ServerProfile`（含启动自愈），解决重登或重新添加中枢后设备始终无法握手连接的问题。
- **分离「退出登录（保留数据）」与「删除中枢（彻底清除）」**：在「远程主机管理」页面拆分为无损保留本地设备缓存的「退出登录」与带二次确认弹窗的级联清理操作「删除中枢」；删除中枢时同步移除其下属 `ServerProfile`、离线快照缓存（`OfflineCache`）、设备发现缓存、中枢目录、`RemotePeerTrustStore` 固定指纹及全部相关加密身份槽，剪枝连接图与设备分组并将有效令牌入队后台服务端吊销（`PendingRemoteRevocation`），同时不影响同宿主机上的其他中枢账号或 SSH 设备。
- **补齐登录态失效探测、全入口一键重登与连接票据续签**：新增 `HubAuthStatus`（`ACTIVE` / `SIGNED_OUT` / `EXPIRED`），综合本地身份槽缺失、令牌作废、Refresh Token 过期及运行态 `RemoteRecoveryKind.LOGIN` 识别登录态失效；在「远程主机管理」、设备管理、设备详情、单机连接栏（`ConnectionStrip`）及多服务器聚合连接栏（`AggregateConnectionStrip`）提供预填中枢地址与账号的一键「重新登录」入口，并在重登时通过 `renewAdoptedPinnedHosts` 为已采纳且公钥一致的主机自动续签连接票据与信任锚点。
- **设备页过期/部分发现自动刷新与离线缓存明确标识**：进入设备详情页时，若所属设备已启用且处于 `ACTIVE` 登录态，但发现结果缺失、已过期或仅为 `PARTIAL` 部分结果，自动触发一次后台刷新不再被旧缓存阻断；完整记录并展示发现补充说明（`discovery.note`）、不完整/过期标记、Harness 槽位不可用原因及离线缓存/登录失效警告，避免将陈旧 Harness 缓存误判为实时在线状态。

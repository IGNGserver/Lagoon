## 本次更新

- 设置页新增「版本与更新」：可直接检查 GitHub Releases、查看更新说明、下载并安装新版本。
- 默认包含预发布版（与仓库发布策略一致），也可切换为仅正式版。
- 下载完成后校验文件大小、SHA-256、包名、versionName、versionCode 与签名证书；debug 包或不同签名的安装包会在调起系统安装器前被拒绝。

- 更新检查独立于 OpenCode / DSH 服务器连接，不读取或修改服务器资料与凭据。

## 本次更新

- **支持 Codex**：通过 SSH 直连或 DSH Remote Host 使用 Codex，与现有 OpenCode、DeepSeek Harness 一样管理连接和会话。
- **常用会话操作**：按连接支持情况使用线程、模型选择、流式回复、审批、问答与协作事件，并支持查询工作区与历史。
- **连接可靠性**：Remote 支持大消息分块、前后台事件订阅和断线后对账；修复首次快照与实时事件之间的序号竞态。
- **审批与删除保护**：宽范围授权需要查看详情后处理；SSH 永久删除仅在已验证的 Codex CLI 0.167.2 上开放。

## 已知限制

- 尚未在物理 Android 设备、已登录的真实账户、生产 Remote Hub 或真实断网条件下验收。
- SSH 使用独立进程，暂不保证断线续跑或附着其他客户端的活动任务；实验性 daemon/proxy 的任务和审批恢复尚未验证。
- Remote 仅支持 Host 白名单及单次审批，通用文件附件、回滚、终端和部分 MCP 交互不可用；完整子代理会话树及真实子代理删除级联尚未验证。
- 本版本为预发布版本，不会标记为 GitHub Latest。

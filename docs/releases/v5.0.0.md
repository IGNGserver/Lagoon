## 本次更新

- **澎湃 OS 4（HyperOS 4）四级表面色阶与排版重构**：
  - 建立统一的 `HyperColorPalette` / `HyperLagoonTheme` 四级表面色阶体系（Level 0 矿石灰/黑曜底板、Level 1 `22.dp` 连续曲率分组大卡片岛配微高光描边、Level 2 交互容器/代码块/用户气泡、Level 3 磨砂玻璃顶栏与抽屉），彻底解决原有界面扁平轻飘的问题。
  - 废除聊天页割裂的橄榄黑 `QoderChatTheme` 异色体系，实现聊天页与首页、设备管理、设置页的全局视觉统一。
  - 重塑标题与正文字重阶梯，并对运行计时器、轮次与数量角标启用 `tnum` 等宽数字排版，消除跳字抖动。
- **澎湃 4 流体物理弹簧转场与无缝预测式返回**：
  - 重写根导航页面转场引擎（`HyperMotion`）：采用临界阻尼弹簧（`dampingRatio = 0.94f, stiffness = 380f`）驱动全幅推入与弹出，底页同步执行 `-28%` 视差位移、`0.94f` 缩放与遮罩压暗，不再出现半透明交叉淡入淡出。
  - 重构预测式返回手势（Predictive Back）：手指松开提交瞬间由 `backCommitSpring` 物理弹簧直接继承当前手势位移走完剩余路程，消除原有的 `delay(240)` 硬切顿挫。
  - 全局交互控件接入 `Modifier.hyperPress` 按压阻尼缩放与触觉反馈。
- **自研澎湃 4 组件库全覆盖**：
  - 自研 `HyperCard`、`HyperGroupTitle`、`HyperRow`、`HyperSwitch`（物理弹簧开关）、`HyperSwitchRow`、`HyperDropdownRow`、`HyperSegmentedTabs`（滑动胶囊分段控制器）、`HyperTopBar`、`HyperIconButton`，全面覆盖首页、会话详情、设备管理、设置与各半屏面板。
- **会话详情页与首页交互升级**：
  - 聊天页底部输入舱上方新增常驻「待你拍板」快捷交互底座（`HyperPendingActionDock`），在单手拇指热区即可一键允许/拒绝权限或查看待回答问题。
  - 工具调用与思考步骤升级为聚合式「工具执行轨迹卡」，点击通过澎湃弹簧半屏抽屉查看时间线明细。
  - 首页顶栏范围胶囊新增实时连接健康度与在线设备计数；顶部任务条升级为高辨识度动态焦点岛（`GlobalTaskStrip`）；会话卡片内联展示正在执行的工具步骤摘要与置顶标记。
- **Core 状态层解耦与流式引擎优化**：
  - 新增 `ConversationStorePool` 多会话独立状态池（LRU 容量 12），按 `(serverId, sessionId)` 隔离会话消息、改动、目标、草稿与分页游标，消除 `MainActivity` 手动维护 `snapshots` Map 的脆弱补丁，父子会话与跨设备切换零闪烁直出。
  - `TranscriptRows` 引入历史已完成 Turn 增量归约缓存（`turnRowCache`），流式输出刷新时仅归约当前活跃 Turn，历史 Turn 直接 $O(1)$ 复用。

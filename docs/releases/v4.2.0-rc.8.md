## 本次更新

- **新建会话不再因为“当前连接没连上 / 本机没登记项目”而报死路**：入口改为按启用的连接计算目标，「全部设备」/设备组先选服务器（harness），空白页再选工作区；服务器离线、连接中或还没有工作区时也能进入空白页并等待重连。
- **服务器列表始终完整**：OpenCode 直连、DSH 远程中枢、DSH SSH 直连三种连接方式统一列出，带 harness 徽标、连接方式与在线状态；不再按“已登记项目”反查服务器，0 个工作区的服务器也不会被隐藏。
- **空白页标题改为「服务器 · 工作区」**：始终可点；工作区来源为本机已登记项目 + 服务器已有工作区（OpenCode `/api/project`、DSH `workspace/follow`）。点选服务器工作区会经 `projectAt` 解析并显式登记，不自动导入服务器项目清单。
- **切换服务器保留已输入正文**：草稿页输入框使用稳定 identity，页面 saveable key 不再包含 serverId；新增草稿意图，空白页打开期间不恢复该服务器上次打开的会话，避免被立即替换或串入旧草稿。
- **删除旧的等待与提示**：移除选择服务器后的 45 秒等待、“无法连接服务器，稍后重试”toast，以及“没有可用项目 / 没有可用工作区 / 设备尚未连接”的死路文案。
- **回归测试**：新增纯函数目标解析、新建流程源码级回归、空白页草稿文本用例；`docs/HOME_REDESIGN.md` 与 `docs/DSH_DEVICE_GROUPING_PLAN.md` 已同步。

## 已知限制

- 本机未连接 Android 真机/AVD，未做视觉验收：标题行高度、harness 徽标与状态点的挤压、深色模式/大字体需要安装后确认。
- DSH 的 `projectAt` 只认 `workspace/follow` 已维护的工作区；服务器目录浏览器里的全新目录仍可能提示“服务器没有解析出这个目录对应的项目”，本次以“服务器已有工作区”列表兜底。
- 服务器端新建工作区后，当前连接的 `workspaceCatalog` 要等下一次读取/重连才出现在“服务器上的工作区”；目录浏览器可立即添加。
- 离线服务器允许进入空白页，发送按钮沿用既有规则禁用，重连后自动可发；本次未新增离线发送队列。
- 预发布版本使用与正式版相同的稳定签名；覆盖安装前请确认与已安装版本签名一致。

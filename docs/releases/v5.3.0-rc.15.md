## 本次更新

- **设备页不再漏设备**：设备列表会把已保存的 SSH 父级直接并入投影。连接图读取失败、版本不兼容或保存落后一拍时，也不会再出现“只显示一台 SSH 设备、其他设备的会话却还在”的情况；连接图不可读时使用只读投影，不覆盖磁盘原文件。
- **Antigravity 工作区恢复中文**：AGY 返回的 `cwd` 可能是 `file://` URI 或百分号编码路径，之前会原样显示成 `%E4%B8%AD...`。现在按 UTF-8 解码后再用于会话、工作区标题和项目键，中文、空格路径都能正常显示。
- **修复 SSH 保活导致的闪退**：SSH 连接建立约十几秒后的第一次保活检查，可能在重连/关闭的竞态中抛出“SSH transport lease closed”并直接结束进程。现在已关闭的连接按“隧道不可用”处理，保活异常只触发重连，不再逃逸成未捕获异常。
- **DSH 隧道建立更可靠**：去掉启动后额外发一次 HTTP/1.0 请求的预探针，改为直接走进程身份证明和真实转发登录；远端缺少 `python3`/`lsof` 时按文档降级为启动记录校验，而不是报“安全检查无响应”。登录失败与隧道失败分开提示，令牌轮换仍会自动重试。
- **SSH 配置部分损坏时可恢复**：`ssh-hosts` 文档里个别条目损坏时，会尽量恢复仍然有效的主机，而不是让设备页整页变空。
- **更完整的回归测试**：新增设备投影补全、AGY 中文/URI 解码、无 `python3` 降级、关闭租约探测等用例。

## 验证

- 本地执行 `ANDROID_HOME=$HOME/Android/Sdk ./gradlew :app:testDebugUnitTest :app:assembleDebug` 通过。
- 全量单元测试 **1911 项、0 失败、22 项按环境跳过**。
- 新增用例覆盖：无 Harness 的 SSH 父级仍显示；旧图缺设备时从 profile 补回 Harness；AGY 百分号编码与 `file://` 工作区；无 `python3` 时安全校验降级；关闭后的租约探测返回 `false` 而不是抛异常。

## 已知限制

- 本机没有 Android 真机，也没有用户的三台 SSH 目标凭据；本轮验证为 JVM 单元测试与 Debug 构建，仍需在真机上复测“添加设备 → 连接 → 断开重连”。
- 如果此前已经把带 `%` 的 AGY 路径登记为本机工作区，历史登记不会自动改写；在服务器工作区列表里重新点一次即可覆盖。
- 远端缺少 `python3`/`lsof` 时只做启动记录校验，理论上弱于 socket 属主证明；诊断里会保留降级提示。
- 本版本为预发布版本（pre-release），按 GitHub 规则不会标记为仓库首页 Latest。

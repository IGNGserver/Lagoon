## 本次更新

- **手机新建的会话不再变成「未分组」孤儿**：`session/create` 现在会带上工作区归属。此前只传 `cwd`，Host 只在请求带 `workspaceId` 时才把会话记进工作区，于是手机建的会话在所有「按工作区枚举」的地方——Remote 中枢的会话目录、电脑端工作区视图——都不可见，而且 DSH 没有任何事后补挂的 RPC。现在目标目录正好是某个工作区根目录时改传 `workspaceId`；子目录或未注册目录仍按 `cwd` 创建，保持原有语义。
- **问答选项不再「点一个整组选中」**：问题选项补稳定 `value`，选中状态按选项本身判断，不再随渲染顺序串位。
- **新建会话切换设备不再闪退**：空白页改为自动选设备，进入后先选服务器再选工作区；切换服务器时已输入的正文会保留。

## 已知限制

- 已经存在的「未分组」会话不会自动补挂：DSH 没有 attach 类 RPC，需要在 Host 侧停机窗口一次性修复。
- 本次只修正客户端建会话的请求形状。其它客户端（例如官方 DSH App）若仍只传 `cwd`，同样会留下未分组会话，需要 Host 侧兜底。
- 预发布版本使用与正式版相同的稳定签名；覆盖安装前请确认与已安装版本签名一致。

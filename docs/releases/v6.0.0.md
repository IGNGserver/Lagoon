## 本次更新

- **重大变更：全面转向纯 SSH 架构（移除 DSH Remote 与 HTTP Direct）**
  - 彻底移除 DSH Remote 中继模式（配对、扫码、中继身份与 Pin 缓存）与 HTTP Direct 直连模式，今后 Lagoon 仅通过 SSH 连接远端设备，整套设备域、运行时与界面代码净精简超过 3.4 万行。
  - **覆盖安装自动迁移**：升级后自动执行幂等迁移，完整保留既有 SSH 设备、加密凭据、全局 SSH 密钥库（含 AndroidKeyStore 生物识别/硬件密钥）、TOFU 主机指纹、设备分组、设备级启停状态与所有 SSH Harness 配置；已下线的 Remote / Direct 条目自动清理，并在首页展示一次性可关闭的升级提示条，选中目标自动切回存活的 SSH Harness。
- **纯 SSH 两层单真源设备体系与交互重构**
  - 设备存储收敛为「SSH 设备 → 多 Harness」两层单真源（`DeviceStore`），同一台 SSH 设备可同时挂载并独立管理 OpenCode、DeepSeek Harness、Codex、Claude Code、Antigravity 等多类 Harness，共用底层 SSH 连接并支持自动发现。
  - 重构设备管理、设备详情、添加/编辑 SSH 主机表单与密钥库流程；首页范围切换统一为「按 SSH 设备」与「单个 Harness」视角。
- **自 v5.2.0 正式版以来的累计升级**
  - **多 Harness 原生能力**：通过 SSH 支持 OpenCode、DeepSeek Harness、Codex、Claude Code 与 Antigravity，补齐工作区管理、历史消息分叉、终端、Diff、定时任务与原生能力探测。
  - **SSH 密钥库与安全边界**：支持全局 SSH 密钥库、硬件/生物识别/证书认证，以及按端点绑定的 TOFU 主机指纹校验与隔离的 SSH 编辑器状态。
  - **托管实例与首页连接体验**：托管 `dsh web` 启动/复用前核对安装指纹并在 DSH 升级后自动重启过期实例，使用 `O_EXCL` 文件锁防止并发双启动；OpenCode 服务未运行时可在首页直接触发启动；首页刷新状态与连接/离线/待同步提示收敛为单一来源。
  - **144Hz 高刷与交互流畅度**：重构高刷档位协商、虚拟化列表与流式帧渲染管线，优化单轨预测式返回与整页转场动画，收拢后台活动抽屉与目标/Todo 胶囊。

## 已知限制

- **不向后兼容项**：已移除 DSH Remote 中继与 HTTP Direct 直连模式；原依赖这两类模式的条目会在升级迁移时自动清理，需改用 SSH 连接对应主机。
- 本次纯 SSH 架构与设备 UI 重构尚未在 Android 真机上完成覆盖安装与端到端交互点验；建议覆盖安装后重点确认已有 SSH 设备/密钥（含生物识别钥匙串）/TOFU 指纹/分组保留完好、迁移提示条展示正常，以及新建/编辑 SSH 设备与多 Harness 切换表现。
- DeepSeek Desktop 缺少上游 SSH 附着接口，暂不支持；OpenCode 基线契约不提供 DSH 式会话正文搜索。
- 正式版与预发布版共用同一固定发布证书签名；若设备当前安装的是 debug 包，需先备份配置并卸载后再安装。

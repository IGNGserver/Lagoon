## 本次更新

- **添加第二台 SSH 设备不再串用上一台的状态**：修复整页编辑器共用 saveable 作用域的问题。此前第二次打开「添加 SSH 设备」会恢复上一次的地址、密钥选择和已固定的主机指纹，拿 A 机器的指纹去连 B 就会误报「主机指纹变了」。现在每次打开都是独立实例，旋转或进程重建时同一实例的草稿仍会保留。
- **主机指纹按端点绑定**：已固定的指纹只对探测时的 `host:port` 有效，地址或端口改动后会重新核对；首次信任不再被误判成「指纹变了」，真正变化时仍会显示旧值并要求重新信任。
- **密钥库读取失败会明确提示**：读取失败不再默默显示成空列表，密钥库页面会区分「还没有密钥」和「读取失败」，并提示数据可能仍在磁盘上，避免误以为密钥被删除后又覆盖导入。

## 本次更新

- **DeepSeek Harness 适配补全**：按 `@deepseek-ai/dsh@0.2.x` 的真机契约重写协议层（完整契约见新增的 `docs/dsh-protocol.md`）。修复了此前与 `0.2.0-rc.2` 不兼容的调用信封（payload 必须只含一个 `args` 对象、字段是方法形参名），并改用浏览器式根路径交换换取长寿命 Cookie。
- **鉴权**：`GET /?token=…` 换签名 Cookie 为主（默认 30 天、跨 dsh 重启仍有效，解决「重启要重填令牌」），`GET /connect?token=…&interactions=answer` 的 API Peer 为备选；401 时自动重新交换。
- **实时流式**：消费 `session/follow` 的 `assistant-stream` 帧（`text-delta` / `reasoning-delta`），assistant 文本与 Reasoning 现在实时上屏；耐久消息到达时自动收口，重试会清掉上一次尝试的片段。
- **状态与去重**：`api-session/status` 折算成运行状态（未关注的会话也能实时收尾）；消息页与实时流按事件 `seq` 去重，避免重连/刷新后内容重复；修正 `api-session/removed` 的纯字符串参数。
- **审批与问答**：瀑布事件折算成与其它 harness 相同的权限/表单提示；其他客户端结算时按 `cancel` 帧撤回本地待办并回到运行态；问答表单改为控制器认识的结构，回答按 DSH 的问题 id 结算。
- **新能力**：工作区文件浏览（`workspaceFiles`，列表/预览/二进制提示）、会话改动列表与逐文件对比（`workspace/changes` 摘要 + `/api/changes.summary|diff`）、后台任务状态（`job/list`）、斜杠命令面板与 `/compact`（`commands/list|execute`，不再把命令当普通文本发送）、归档/取消归档、分叉、模型目录与选择。
- **语义差异显式化**：DSH 没有删除会话与消息级回退，分别折算为「归档」与「分叉」提示；引用的服务器文件折算成路径文本随消息发送；已知错误码折算成中文文案。
- 文档：新增 `docs/dsh-protocol.md`（认证、传输、命名空间、事件与帧、限制），更新 README 与 `docs/ARCHITECTURE.md`。

## 已知限制

- DSH 处于 developer preview，跨版本可能破坏性变更；适配按 0.2.x 形状实现，未知错误码/形状以明确失败呈现（`gateway/arguments-invalid` 会提示更新 Lagoon 或 dsh）。
- DSH 没有删除会话、消息级回退与文件搜索；改动摘要只在 dsh 进程内、会话存活期间提供（重启后旧轮次没有对比）。
- 工作区文件访问需要会话身份；没有会话的目录无法浏览。引用的服务器文件以路径文本发送，文件附件（receipt）暂不支持。
- 真机验收仍需在目标设备与真实 DSH 实例上完成：发送、停止、审批与问答回应、多客户端结算撤回、Android 16 实时更新计数。

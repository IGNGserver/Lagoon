## 本次更新

- 新增「从中枢导入」：中枢网页「设置 → 客户端接入」为每台设备生成接入密钥，把生成的导入链接粘贴到 Android 客户端「设置 → 从中枢导入」，即可一次导入中枢里配置好的 OpenCode 与 DeepSeek Harness 服务器，包括访问凭据。
- 导入前先预览：每台服务器标出「新增 / 更新（列出变化的字段）/ 无变化 / 冲突 / 中枢已移除」，由用户逐台勾选。导入时每台服务器限时测试连接；连不上的仍会保存，并在结果中列出。
- 去重：已从同一中枢导入过的服务器就地更新，保留本机的任务记录、草稿与通知设置；同一地址的手动添加服务器合并为一台，不会重复添加；中枢已删除的服务器默认不移除，需要勾选确认。
- 中枢「客户端接入」支持查看每把密钥的创建时间、最近导入时间和来源地址，并可逐个吊销；导入内容用密钥加密传输，经 HTTP 访问的中枢也不会在网络上暴露凭据。
- 中枢服务器编辑页新增可选的「客户端访问地址」：中枢只能在容器内访问的地址（如 `host.docker.internal`）可在这里填写另一个地址，导入时使用它。
- 中枢新增持久的中枢标识，客户端据此识别同一中枢导入过的服务器。

## 已知限制

- Android 的「从中枢导入」界面只做了编译和单元测试，尚未在真机或模拟器上完整走过；请在真机上验证导入、预览和再次同步。
- 同一台开发机用两个不同地址访问（如局域网 IP 与 Tailscale）时，会被识别为两台服务器。
- 导入是一次性的快照：中枢之后的改动不会自动同步到手机，需要在设置里再次「从中枢导入」。
- 接入密钥可以导出全部服务器的凭据，应当像访问密码一样保管；「退出所有设备」不会吊销接入密钥。
- 本版本不改变既有的 iOS 主屏 PWA 与 Android Chrome 推送的验收状态，这些仍需真机验证。

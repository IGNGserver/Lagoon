## 本次更新

- 后台 shell 与子会话不再被当作根会话“运行中”：AI 回复完成后，首页立即显示未读蓝点、发送完成通知，灵动岛不再因为后台活动保持活跃。
- 首页列表用低调的 7dp 空心小圆环表示“根执行已结束，但家族仍有后台命令或子会话”，不替换蓝点、不改变排序或分组。
- 会话输入框上方新增后台活动入口；「子会话与后台」面板可查看运行中的 shell、历史/运行中子会话及其实时状态，并进入子会话查看。
- 后台命令支持查看实时输出：按服务端绝对字节游标只保留最近 64KB，支持停止命令；不支持该接口的实例会明确提示不可用。
- 子会话页面改为只读状态栏：显示运行中/等待/完成/失败/中断、已用时间、agent 与模型，并提供“返回父会话”；导航按父链维护，兄弟会话不会错误加深返回栈。
- 通知口径：仅有后台活动时使用独立的低优先级、不申请提升通知，不进入灵动岛；根会话重新运行时再恢复正常实时更新。
- 中枢与网页端同步新口径；中枢新增后台命令输出/停止接口，网页首页增加低调后台标记，会话页增加后台入口、输出查看与子会话只读栏。
- 迁移旧持久化数据时丢弃合成出来的 `background=true` 运行态，避免升级后残留永久“运行中”。

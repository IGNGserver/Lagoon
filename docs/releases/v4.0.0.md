## 本次更新

- Lagoon 自本版本起只维护 Android 客户端。移除 v3 的 Lagoon 中枢、网页/PWA 客户端、docker compose 部署文件、中枢镜像发布链路及中枢相关文档。
- 移除 Android 设置中的「从中枢导入」。已经保存在本机的服务器资料、任务记录、草稿和通知设置不受影响；服务器仍直接连接 OpenCode 2.x 与 DeepSeek Harness。
- 保留并继续维护 DSH Remote 接入（仍为实验性能力：部分流程尚未完成真实 Host 和真机验收）。
- 简化构建与发布：Gradle 只包含 `:app`，Release 只产出 Android APK，不再构建中枢镜像或上传 compose 文件。官网与更新源不变。
- 中枢停止维护的说明见 `docs/HUB_EOL.md`；历史设计可查阅 tag `v3.1.0-rc.6`。

## 验证

- 已执行 `ANDROID_HOME=/home/lvziw/Android/Sdk ./gradlew :app:testDebugUnitTest :app:assembleDebug`：582 项测试通过（1 项需要真实 DSH Remote Server 的集成测试按预期跳过），Debug APK 构建成功。
- 已执行静态检查：Gradle 只配置 `:app`；仓库不再包含 `hub/`、`web/`、`deploy/`、`contract/` 或中枢导入代码的引用；发布工作流不再包含中枢镜像任务。

## 已知限制

- DSH Remote 仍缺少真实 Host 互操作与真机验收。
- 中枢下线后，iOS、iPadOS 和桌面浏览器不再有官方客户端。
- 旧版中枢镜像与 Release 资产可能仍可下载，但不再受支持，也不应继续部署。

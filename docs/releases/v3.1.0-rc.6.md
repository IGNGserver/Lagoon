## 本次更新

- 会话状态与官方一对一对齐：修复首页会话行把部分会话误标为「状态待确认」以及把已完成会话显示为「错误」的问题。
- 权威结局判定：只有服务端权威返回的 `succeeded` 或 `failed` 才记录为未读结果；空或未知 `outcome` 保持「状态待确认」，不提前判定为已完成或失败。
- 异常边界收敛：`session.error`（如 Provider 错误、临时模型报错）不再把整轮任务阶段打成失败；子会话生命周期仅在明确的 `completed`/`error`/`cancelled` 时收尾。
- 首页会话行显示对齐：未读失败在右侧明确标注「错误」（红色），未知状态在右侧标注「状态待确认」（次级文字色），与安卓原生及网页端完全一致。

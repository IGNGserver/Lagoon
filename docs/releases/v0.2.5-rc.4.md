## 本次更新

- 修复刷新时偶现 `StandaloneCoroutine was cancelled` 报错：被取代的刷新不再把协程取消当成失败提示。
- 修复首页长期显示“部分数据待同步 · 下拉重试”：已删除的 worktree 目录会让服务端返回 500，现在按目录退避重试，只有影响当前可见状态的读取失败才标记待同步；离线的服务器不再被显示为“待同步”。
- 恢复服务器资料里「自动连接此服务器」开关的作用：关闭后不再常驻后台连接，点开该服务器时才建立连接。
- 修复多服务器模式：服务端已删除的会话不再残留；“全部服务器”列表中的状态与通知按服务器归因；离线服务器上失联的运行任务不再永久占用灵动岛与前台服务。
- 通知修复：同一轮中的第二次提问也会提醒；删除服务器或关闭通知会撤销该服务器的旧通知；关闭通知的服务器不再进入全局汇总；权限被电脑端处理后手机上的“需要授权”通知会撤下。
- 自动授权失败改为退避重试，不再每轮对账重复请求；实时事件触发的控制面读取合并窗口放宽到 3 秒，降低多服务器同时输出时的请求量。
- 离线缓存更可靠：超限时保留最新消息并标记“不完整”（不再让旧缓存冒充完整会话），补充保留排队/重试/上下文整理状态与撤销边界；缓存完整性检查不再卡在主线程。
- Agent 选择器改用服务器实际提供的 agent 列表；目录浏览器与搜索结果去重；问答表单的异常字段不再导致页面崩溃。
- 服务器返回的失败原因（字符串或嵌套对象）统一解析；工具报错为字符串时也能显示。
- 其他：跨服务器切换保留尚未发送的手机附件；通知深链不会在屏幕旋转后重复跳转；选择新会话目标失败时有明确提示；后台定时同步超时/失败会退避重试；发送目标已切换时明确提示而不是静默丢弃。

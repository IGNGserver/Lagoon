## 本次更新

- 发布 Lagoon 3.0 正式版：包含原生 Android 客户端、自托管 Lagoon 中枢和可安装的 PWA 网页客户端，支持连接 OpenCode 2.x 与 DeepSeek Harness。
- 新增中枢与网页能力：多服务器常驻监控、远程会话与文件操作、授权和问答、模型及 Agent 选择，以及任务结果与待处理请求的 Web Push 通知。提供 amd64 / arm64 Docker 镜像及版本化 compose 部署文件；凭据加密保存在中枢数据卷。
- 修复任务结束后长期停在“后台任务运行中”的问题：当前连接与全部服务器概览共用任务对账，核实前台执行、子任务、后台 Shell 和待投递输入后再收尾。
- 修复打开旧会话、重启或切换服务器后历史后台状态重新出现的问题。离线或读取不完整时显示“状态待确认”，不再把旧记录当成仍在运行，也不会凭读取失败虚报完成。
- 修复子任务较多时核实进度停在固定上限、后台 Shell 的所属会话解析不完整，以及部分权限和表单读取可能误清其他会话请求的问题。
- 修复消息读取与实时事件的竞态，避免较早的 HTTP 响应覆盖新文本或把已完成的工具重新显示为运行中；保护已接收但尚未执行的新输入，不再误用上一轮执行结果。
- 调整工具异常的提示层级：历史命令的“退出码 1”等诊断保留在命令详情，分组中性汇总异常数量，不再误导为整个会话失败；真正的助手或会话错误仍保留错误提示。
- 修复 Android 日期分组：持续运行、后台运行和等待处理的任务，即使没有新活动，也归入“今天”；不改写服务端时间，保留置顶与组内顺序。
- 延续 v3 预发布版对 DeepSeek Harness 消息投影的修复，避免将注入给模型的运行环境和时间信息显示成用户消息。

## 已知限制

- 尚未在用户截图对应的手机和真实服务器上完成本轮修复的人工验收；目前验证来自自动化 HTTP / SSE、持久化、重启和事件竞态回归测试。
- 尚未完成 iOS 主屏 PWA 和 Android Chrome PWA 的推送、键盘真机验收。Web Push 需要 HTTPS，并依赖中枢访问浏览器厂商推送服务的外网连接。
- API 不可用、目录退避或单轮核实预算不足时，任务会保持“状态待确认”，等待后续成功读取；不会推测远端任务已经完成。
- 中枢不缓存完整会话历史，每次打开会话读取最新一页，更早消息按需翻页。
- 安装包继续使用既有稳定证书；早期调试签名安装包不能直接覆盖升级，迁移前应保存服务器配置。发布不会自动部署到任何设备。

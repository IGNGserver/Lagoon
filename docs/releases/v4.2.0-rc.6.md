## 本次更新

- **修复首页“离线缓存”误报**：设备组 / 全部设备只有在所有成员都离线时才显示离线缓存；单台设备离线，或当前会话正文来自缓存，不再把整页钉在黄色横幅上。离线成员继续由设备 chip 的状态点表达。
- **修复“部分数据待同步”常驻**：聚合页只统计已连接服务器的读取失败；离线设备的读取失败不再点亮整页提示。
- **刷新遇到传输中断会自动恢复**：DSH Remote 的 relay / WebRTC / RPC 临时断开（例如 `transfer closed`）不再作为业务错误弹出，也不会停在错误状态；保留现有数据并按 2–60 秒退避自动重连。登录失效、指纹变化、主机不存在等需要用户处理的错误仍保留原提示和修复入口。
- **减少重复错误提示**：离线与重连失败只进入横幅、连接条和诊断日志，不再每次重连都弹 toast。
- **设备组视图移除“查看全部”**：设备组是容器而不是筛选，去掉该按钮，避免点按后意外跳出当前组。
- **回归测试**：新增离线缓存聚合、传输故障分类、离线提示与设备组按钮可见性测试。

## 本次更新

- **SSH 换代不再把登录清掉**：远端 `dsh web` 重启后先用新的启动令牌登录。令牌已轮换时，退回这条 SSH 连接上记住的 Cookie，不再提示去粘贴启动链接。
- **断开后事件会跟上新进程**：SSH 或远端 `dsh web` 换代时，会话事件流结束旧连接并绑定新的一代，不会停在已经关掉的 WebSocket 上。
- **改完配置会立刻生效**：保存主机会关掉旧隧道再按新地址、密钥和启动命令连接。编辑页的「测试连接」用当前表单单独拨号，不会把旧连接的成功当成新配置可用。
- **工作目录和已有实例会明确失败**：填写的远端目录不存在就停止启动。这台机器上已经有别的 `dsh web` 时不再启动第二个。没有明确项目目录时，新建会话使用填写的工作目录。
- **保活不再把卡住的端口当成还活着**：探测改为向远端 loopback 发一次 HTTP 请求，必须看到 HTTP 响应。主机密钥同时核对类型和指纹；配置损坏时拒绝覆盖其余主机。

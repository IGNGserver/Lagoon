## 本次更新

- **DeepSeek Harness 不再动不动掉登录**：dsh 每次启动都会换新的启动令牌，而此前 Lagoon 只保存令牌、会话 Cookie 只放在内存里，App 被系统杀掉或 dsh 重启任一发生就要重新配对。现在换到的浏览器 Cookie 会经 Android Keystore 加密保存在本机，App 与 dsh 重启后都直接复用；dsh 未重启时 Cookie 还会在后台自动续期。
- **配对更省事**：添加 DSH 服务器时可以直接粘贴 `dsh web` 打印的整条启动链接，地址和令牌自动拆开。
- **新增「签名密钥」配对方式（可选）**：填写电脑上 `~/.dsh/.credentials.yaml` 中 `client-connection/browser-session` 记录的 `secret`，手机即可自行签发会话 Cookie。配对时不需要看电脑上的启动链接，dsh 重启、Cookie 过期也不用重新配对；删除该记录并重启 dsh 即可吊销。请只在 HTTPS 或可信局域网中使用。
- **登录失效时说清楚**：Cookie 真正失效时会提示「重新配对」并放慢重试，不再当成网络抖动反复刷新；地址未被 dsh 信任（403）时提示使用 `--host` / `--trusted-host`。
- **连接更稳**：实时连接增加 20 秒心跳；事件流断线重连后会和服务器重新核对待处理的审批与问答，断线期间已在别处回答的提示会自动消失；打开的会话断线后自动重连，并补上断线期间的内容。
- **功能补齐**：文件搜索、Agent 预设列表与切换、在还没有会话的目录里浏览并添加项目。
- **修复附件**：之前发给 DSH 的图片附件会被悄悄丢掉，现在图片和文本文件附件都能正常发送。
- **修复新建会话**：带标题新建 DSH 会话时，不再因为请求里多出 `title` 字段而失败；新会话也能及时出现在总览里。
- **界面按 harness 区分**：DSH 会话菜单提供「分叉」与「归档」，不再显示 DSH 不支持的「删除」；OpenCode 的界面保持不变。

## 已知限制

- 本版 DSH 改动依据 dsh 源码（2026-10 master）与模拟服务器验证，尚未在真实 dsh 实例和手机上逐项验收：重点需要确认强杀 App 并重启 dsh 后免配对、签名密钥模式、断网恢复后的审批对账。
- 签名密钥模式依赖 dsh 内部的 Cookie 格式；dsh 改动格式时会提示密钥被拒绝，届时请改回「启动令牌」方式。
- 令牌方式下 Cookie 默认 30 天绝对有效期；dsh 期间重启过、且 Cookie 到期后需要用新的启动链接重新配对。可在 dsh 配置中调大 `cookieMaxAgeDays`（写法见 `docs/dsh-protocol.md`，尚未实机核对）。
- PDF 等非图片的二进制附件仍不支持（与 OpenCode 一致，只发送图片与文本文件）。

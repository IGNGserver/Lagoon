## 本次更新

- **修复 DSH Remote 会话内容整页空白**：读不到会话时不再静默显示空页面，而是给出具体原因；首屏快照补上 `assistantStream`，正在生成的回复也能看到；首帧必须是快照，否则重试一次并明确报错。
- **凭据刷新自愈**：进程被杀、断网或超时导致刷新中断后会自动重试，不再需要重新登录才能恢复；只有中枢明确拒绝（401/403）才提示重新登录，且不会丢失已保存的设备凭据。
- **单帧故障不再拖垮整台设备**：一条流的坏帧只让该流失败，其他会话与 RPC 照常工作；未知消息类型与未知控制帧忽略并计数，中枢升级不再让连接整体失效。
- **支持中枢下发的独立 Relay 数据通道**：按 `relay.attach → relay.ready → transport.selected → secure.handshake` 自动附加，就绪后业务密文只走该通道；以前遇到这种中枢会直接放弃连接。
- **一台主机只保留一条加密连接**：首页监控、打开的会话与「测试连接」共享同一连接并引用计数，不再互相顶掉。
- **实时事件缺口自动补齐**：`session/follow` 出现 seq 缺口时用 `session/page` 补齐再投影；子代理会话改用 `kind:"subagent"` 地址投递；空会话（`cursor=-1/0`）也能继续翻页。
- **协议代际自动适配**：`workspace/follow` 的参数形状按代际回退（0.2.1 线用 `{args:{}}`，更新代际用 `{args:{request:{}}}`），不再把代际写死。
- **排障能力**：连接与能力协商失败带上底层原因；每次会话快照记录 `records/messages/cursor/hasMore`（不含内容），可用 `adb logcat -s DshApi` 定位空白会话。
- **设备命名去重修正**：名称只在设备范围内比较，修复 Harness 同名导致的 “(2)” 后缀。
- **添加入口统一**：改为 OpenCode 直连 / DSH 远程中枢 / DSH SSH 直连三条对等通道；设备管理与设备组按体系与连接方式展示，异常提示统一为「DSH 远程中枢」。

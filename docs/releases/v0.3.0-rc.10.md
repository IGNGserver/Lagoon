## 本次更新

- 修复快速侧滑返回时被系统识别为退出应用：从会话页或弹层收起键盘后紧接着返回，应用内仍有上一级时不再直接退到桌面；根返回回调与导航栈同步启停（#129）。
- 修复向上加载更早消息时滚动位置跳动：转录列表改为反向布局，加载的历史追加在列表末端，视口不再移动；内容不满一屏的短会话也会自动预取历史（#130）。
- 减少输入与键盘弹出时的整页重组：输入框自己保存文字，每次按键不再刷新全局状态；未打开的菜单不再读取键盘高度（#131）。
- 降低流式输出时主线程的开销：会话、父子链、任务汇总按状态缓存；任务只在变化时写入本地存储，运行中的用时基线最多每 5 秒写一次（#132）。
- Markdown 在后台线程预先解析，缓存扩大到 256 行，往回翻阅长会话时不再在帧内解析；运行中的操作明细浮层持续更新（#133）。
- release 安装包启用 R8 裁剪与优化，体积由约 10.3 MB 降到约 3.6 MB；符号名保持不变，崩溃日志可直接阅读（#134）。
- 首页运行中会话不再在手指按住或滚动时重新排序，松手后再以动画调整；列表接近末尾时自动加载更多会话（#135）。
- 顶部提示不再拦截其下方的返回与菜单按钮，错误提示停留 4 秒；操作明细浮层有进出动画；旋转屏幕后打开的服务器与项目弹层保持打开；复制按钮、附件移除按钮的点击区域放大到 40dp。

## 已知限制

- 以上改动均未在 Android 真机或模拟器上验证：没有可用设备，本机为无虚拟化的 VM。
- R8 Release 包尚未冒烟测试。请在安装后重点检查：连接服务器、打开会话、流式输出、通知、后台同步（WorkManager）、应用内更新、图片附件。
- 顶部提示不再可点击后，点击穿透到下方按钮的行为依据代码推断，尚未在设备上确认。
- 首页重排的「按住时保持顺序」与松手后的动画，需要在运行中会话较多的服务器上实际观察。
- 「复制诊断」新增的按页面帧耗时（卡顿率、P50/P90/P99）需要在真机上取得，用于确认流畅度改进是否有效；本版本没有给出改造前后的数字。
- 从子会话返回父会话时的手势预览页仍然缺失，本版本未改变。

## 本次更新

- **连接更丝滑，开屏与切会话即刻上屏**：
  - 启动与重连时优先使用本地缓存/内存快速渲染会话列表与选中的会话内容，不等控制面全量读取完成；
  - 增加内存 LRU 缓存，在最近查看过的多个会话之间来回切换瞬间呈现；
  - 头部新增连接状态栏（连接中 / 读取中 / 同步中 / 准备就绪 / 重试中）：正常秒连不打扰，慢连接（超过 600ms）清晰展示所处阶段，超时（8秒）主动提示网络较慢，重试带有倒计时并支持一键「立即重试」。
- **重连中支持输入与暂存发送**：
  - 断线或正在重连期间发送按钮不再禁用，输入内容可直接点击发送并进入「等待连接后发送」状态；
  - 连接就绪后自动投递至服务器；若离开会话或切换服务器，暂存内容自动退回草稿箱，避免误丢输入；
  - 成功连接后自动后台预取最近 3 个会话首屏内容（仅限非计费网络与 OpenCode）。
- **控制面并行分级读取，大幅压缩等待时间**：
  - 探测、OpenAPI 契约、会话目录与活动状态并发请求，会话列表就绪即开放交互，无需等待全量信息读取；
  - 审批与问答读取提前并发，流重连时仅拉取控制面与尾部增量，不再全量重跑目录树与文件 diff。
- **实时事件流更敏锐、假死即刻自愈**：
  - OpenCode 事件流增加 90 秒无字节超时自动断开重连；
  - 监听 Android 默认网络切换（Wi-Fi / 蜂窝网络）以及后台超过 1 分钟切回前台，主动重置失效的长连接；
  - TCP 连接超时从 10 秒缩短至 6 秒，对不可达服务器反馈更迅速。
- **连接耗时埋点与诊断增强**：
  - 全链路记录首屏快照渲染、目录就绪、可交互、实时流连通与完整会话就绪各阶段耗时；
  - 诊断信息中包含连接阶段耗时、HTTP 请求量与峰值并发，便于定位网络瓶颈。

## 已知限制

- 重连期间暂存发送机制目前单会话最多保留一条（后续追加的文字会合并至同一条），切服或退出会话时保留为草稿，暂不支持多条独立离线队列。
- 弱网下事件流快速重连依赖设备网络状态回调，极端 NAT 丢包场景可能仍需等待 90 秒心跳超时触发重连。

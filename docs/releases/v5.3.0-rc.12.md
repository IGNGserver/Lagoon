## 本次更新

- **密钥库「导入私钥」不再闪退**：应用清单此前没有声明生物识别权限，打开导入对话框时系统在查询生物识别能力时直接抛出权限异常，界面还没画出来进程就被结束。现已补上权限声明，并在查询失败时按「不支持生物识别」降级，不会再影响对话框打开。
- **「生成新密钥」同样修复**：生成对话框复用了同一段能力查询，之前点击也会闪退，现已一并恢复正常。
- **生物识别解锁恢复可用**：同一个权限也是系统生物识别弹窗的前提。带指纹 / 面容的设备在生成或导入密钥时可以选择「生物识别解锁」，硬件密钥的解锁验证也走这条链路。

## 已知限制

- 模拟器没有指纹硬件，生物识别弹窗本身没有走到；带指纹的真机上需要实际验一次「生物识别解锁」策略与硬件密钥解锁。
- 本机默认环境仍会让 4 项 SSH 隧道用例失败（同一测试在未改动的 `main` 上同样失败，CI 上通过），与本版本改动无关。
- 本版本为预发布版本（`pre-release`），按 GitHub 规则不会标记为仓库首页 Latest。

## 本次更新

- **支持 Antigravity**：通过 SSH 直连或 DSH Remote Host 接入已登录的 AGY，与设备上的其他 Harness 分别管理连接和会话。
- **常用会话操作**：浏览工作目录与历史、创建和继续会话、发送文本及受支持的图片，查看流式回复和工具输出，并按当前会话提供的选项切换模型和思考档位。
- **权限与提问**：按 AGY 实际提供的选项处理权限请求，支持单层字符串表单；Remote 侧仅开放单次授权。
- **连接与工作区**：只读浏览工作区文件；Remote Host 启用相应能力后可使用会话终端。兼容 AGY 1.5.8 返回多工作目录会话时的目录信息，并隔离事件流过载对其他连接的影响。

## 验证

- 功能提交通过 GitHub Actions「构建与测试」，包括 Android 单元测试、Debug 构建、固定上游 Host 连接器和 Noise 互操作测试。
- 本机隔离构建区执行 Android 全量单元测试和 AGY 专项回归测试；Host 网关、DSH changes 和 Remote 终端测试通过。
- 在 macos-dev 使用已登录 AGY 1.5.8 验证 SSH 连接、工作目录、会话创建、模型切换及重连历史；真实 AGY 网关经模拟 Relay 与实际 Noise 客户端的互操作测试通过。

## 已知限制

- 真实测试账号额度已耗尽，尚未验收正常模型生成及真实权限审批或表单；尚未在 Android 真机或已部署的 Remote Host 上验收。
- SSH 需要开发机提供 Python 3、SFTP 和已登录的 `agy`；连接断开可能中断正在执行的轮次，暂不提供应用内终端。
- Remote 需要安装 Lagoon Host 连接器；终端取决于 Host 是否启用相应能力。Remote 单个工作目录达到 100 条会话时会提示列表可能不完整。
- 当前不支持 AGY 文件搜索、Remote 文件引用，以及会话重命名、归档、删除、分叉、回退、压缩和斜杠命令。
- 本版本为预发布版本，不会标记为 GitHub Latest。

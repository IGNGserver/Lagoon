## 本次更新

- DSH Remote 多主机接入：支持浏览器 OAuth/二维码登录、账号级主机目录、逐台指纹核对与信任变化提示，并提供远程主机管理页；添加/编辑服务器不再要求手动输入指纹。
- 远程控制补全：工作区文件上传、排队消息编辑/插话/撤回、后台任务 `job/follow` 输出，以及连接详情中的 Relay 路径、Noise IK、版本、指纹和加密 RPC 往返测量。
- 连接失败按类型给出恢复入口：重新登录、核对指纹、刷新主机、重新连接；同一 Host 的测试连接复用已有 monitor client，避免替换活动连接。
- 主机设置：可填写任意 Host 凭据引用（默认 `DEEPSEEK_API_KEY`）；可创建单模型自定义 pi-ai 服务商路由；可远程开关官方插件 bundle。安装/卸载和完整 schemastery 表单仍在电脑上完成。
- 子代理续聊：只对 `continuable` 子代理显示“继续”入口，一次性子代理保持只读。
- 会话目标条与定时任务只读列表：目标支持创建、暂停、继续、完成、清除；定时任务沿用官方 `schedule_create` 创建，客户端只读展示。
- 文件预览：图片、PDF 首屏，以及 Office（doc/docx/xls/xlsx/ppt/pptx）转 PDF 后的首屏预览。
- 多主机首页新增服务器聚合、手动设备分组与 Harness 标识；远程主机目录仍是唯一 Host 目录来源。
- 新增 WebRTC 可行性评估，结论为 Host 侧尚无信令/传输能力，当前继续使用 Relay，不在本版本实现 LAN/P2P/TURN。

## 已知限制

- 尚未在真实 DSH Remote Host 和真机上完成端到端互操作验收；登录、上传、后台输出、Office 预览、插件开关和目标条仍需真机联调。
- Office/PDF 只渲染第 1 页；多页、文本选择、下载未做。
- 定时任务仅只读列表，编辑/删除/历史未做；目标编辑未做。
- 自定义模型服务商当前只支持单模型最小路由；多模型、headers、compat、重试策略和已有路由编辑未做。
- `job/kill` 不在 DSH Remote allowlist，客户端不提供后台任务停止。
- WebRTC 只有评估，没有实现；Host 提供信令能力前继续使用 Relay。
- 旧版不同签名 APK 的覆盖安装迁移仍需按 `docs/ANDROID_SIGNING.md` 处理。

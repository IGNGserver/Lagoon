## 本次更新

- **会话列表显示所属工作区**：首页与已归档页的会话行在标题下新增一行低对比工作区名；单服务器只显示工作区名，设备组 / 全部设备显示 harness 徽标 + 设备名 · 工作区名，长名称自动省略。
- **OpenCode 与 DSH 共用一套解析**：优先本机登记的项目名，其次服务端项目/工作区标题（OpenCode `/api/project`、DSH `workspace/follow`），最后回退到会话目录名；`C:\...` 等 Windows 路径同样可识别。
- **服务端标题只读、可失败回退**：OpenCode 项目清单按 10 分钟 TTL 复用，单次读取 3 秒超时、失败后 5 分钟退避；DSH 直接读 `workspace/follow` 已维护的清单，不为标签额外开流。读取失败、离线或冷启动时回退到目录名，不阻塞首页，也不会点亮「部分数据待同步」。
- **不新增项目筛选**：工作区标签只做展示，不参与范围筛选、项目计数、排序或新建会话目标；现有「全部会话 ⌄」范围、项目分组和新建目标均未改变。
- **智能去重与消歧**：列表已按项目/工作区筛选，或当前分组标题正好是该工作区时不重复显示；「未归入项目」分组仍显示兜底目录名。同一服务器出现同名不同路径时显示父级一段（如 `work/Lagoon`）。聊天页副标题复用同一套解析。
- **DSH 时间线首屏与轮次边界修复**：`session/follow` 首帧改为整窗装入完整 turn 窗口，不再用消息级 `size` 二次截断；更早页带 `turnWindow`，从 `turn/start` 开始；`turnId` 保留轮次边界，goal / 自动继续 / 压缩检查点不再并入上一轮，并折成紧凑 notice。

## 已知限制

- 未在真实手机上做视觉验收（本机无 AVD、未连接设备）：行高、长名称省略、深色模式与字体放大需要安装后确认。
- 服务端工作区标题在离线或冷启动时回退到目录名，且不写入离线缓存；OpenCode 标题读取失败后最多约 5 分钟才重试。
- DSH 历史窗口依赖 Host 的 `turnWindow` 支持；旧 Host 会走降级重试，但更早页面仍可能按消息数切分。
- 预发布版本使用与正式版相同的稳定签名；覆盖安装前请确认与已安装版本签名一致。

## 本次更新

- **SSH 首屏验证方式**：添加与编辑 SSH 设备时，首屏即可在「密码」「密钥」「密钥优先（`publickey,keyboard-interactive,password`）」之间切换，无需进入折叠选项。
- **私钥真解析与精确报错**：使用 JSch / BouncyCastle 校验导入或粘贴的私钥（支持 OpenSSH v1、PEM、PKCS#8 与 PuTTY `.ppk`），阻止误把公钥当私钥保存，按实际加密状态显示算法、SHA-256 指纹与口令输入框。
- **应用内生成密钥与一键装公钥**：支持在手机端生成 Ed25519、ECDSA P-256 与 RSA 4096 密钥对（含 `aes256-ctr` + `bcrypt` 加密私钥），支持复制 OpenSSH 公钥及一键幂等安装到远端 `~/.ssh/authorized_keys`。
- **全局可复用 SSH 密钥库**：支持独立管理与多主机复用密钥；旧版主机内联私钥可一键迁移进全局密钥库。
- **硬件密钥库与解锁策略**：支持在 AndroidKeyStore 生成不可导出的硬件 ECDSA P-256 SSH 密钥；支持「每次连接询问口令（仅驻留进程内存）」与「生物识别解锁」策略，连接遇到锁定时可直接触发解锁并重试。
- **OpenSSH 用户证书**：支持为软件密钥与硬件密钥附加 `-cert.pub` 用户证书，并在 SSH 会话中启用对应 `*-cert-v01@openssh.com` 公钥认证算法。

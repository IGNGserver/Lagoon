## 本次更新

- 修复 DSH Remote 自建/托管中枢登录时误报 `HTTP 401, AUTH_INVALID`：登录成功后改用账号级 `GET /api/v1/account/devices` 拉取主机目录，不再拿 8 小时账号 token 调用只接受设备 token 的 `/api/v1/devices`。
- 登录后的主机列表按 `role=host` 过滤 Client 设备，只展示可接入的 Host；主机身份公钥直接来自账号目录，继续走指纹核对后接入。
- 刷新已保存主机仍使用设备 token，不影响原有连接、多主机并行和会话恢复。
- 登录失败文案改为明确提示“账号或密码不正确”；账号目录失效提示“登录已失效”；中枢版本过老时提示升级，不再把协议错误误报成密码错误。
- 缺少身份公钥的主机会显示为“身份不可用”，不会让整批登录失败，也不会被误标成“指纹变化”。

## 已知限制

- 灵动岛与首页全局行不承诺与 `/api/session/active` 的会话数逐一相等；子代理 / 后台 shell 按根会话折算。
- 关闭通知的服务器不进入系统灵动岛；应用内全局行会标注但不计入。
- 停止监控的服务器会移除其快照（含未读）；重新连接后从账本恢复。若希望未监控服务器的未读继续留在全局行，需要后续讨论。
- 首页「全部服务器 · 全部项目」任务行是新增的轻量 UI，可能仍需按真机截图微调间距与字号。

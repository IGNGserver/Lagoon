## 本次更新

- **DSH Remote 登录态稳定性与刷新自愈**：引入进程级按槽位 Singleflight 并发去重、`NonCancellable` 落盘与单调 `slotEpochs` 隔离，消除并发请求或协程取消导致一次性 `refreshToken` 丢失及误报「Remote 登录已失效」；追加 `invalidated` 守卫与双跳刷新恢复。
- **401 响应式重放与协议前向兼容**：对 REST 接口与 WebSocket 建连遇到的 `TOKEN_EXPIRED` / `AUTH_INVALID` / `AUTH_REQUIRED` 执行单次响应式刷新重试；修复 `error.details` 为 `null` 时丢失错误码的问题，放宽令牌响应字段校验，提升 `dsh-device:<UUID>` 账号长度上限至 `320`；保留已建立的 `PINNED` 信任并透传瞬时网络/5xx/404 异常。
- **长连接关闭语义与空闲加密保活**：识别服务端 WebSocket 关闭码（`TOKEN_EXPIRED`、`DEVICE_REVOKED`、`SERVER_SHUTDOWN`、`HEARTBEAT_TIMEOUT`、`CONNECTION_REPLACED`、`SLOW_CONSUMER`），并在静默满 45 秒后发送加密 `harness.transport.describe` 保活探测。
- **设备注销清理与分级恢复引导**：退出登录或删除设备时同步使本地槽位失效并调用服务端设备吊销接口；注册遇到 `403 DEVICE_REVOKED` 或身份冲突自动轮换密钥重试；按 `RECONNECT` / `HOST` / `TRUST` / `LOGIN` 精确分流恢复动作。
- **扫码设备配对（Scan-to-Pair v1）**：支持 `dsh-pairing-v1` 与 `fragment-ticket-v1` 短链接二维码及旧版 JSON 二维码（支持相机实时取景、相册选图与手动粘贴），使用 X25519 + HKDF-SHA256 + `X-DSH-Pairing-Proof` HMAC-SHA256 完成配对认领，提供 HTTP 明文显式授权、64 位十六进制 SHA-256 Host 指纹核对、`FLAG_SECURE` 防截屏 8 位配对码展示、仅前台轮询及配对成功后自动连接。

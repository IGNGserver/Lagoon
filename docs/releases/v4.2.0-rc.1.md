## 本次更新

- 设备管理重构：首页设备条只保留「全部 + 显式设备组」，移除末尾加号；未分组连接不再单独占 tab。新增独立「设备管理」页，聚合全部设备、设备组、DSH Remote Hub、未分组设备和 Harness，并提供「添加设备」入口。
- 添加设备页改为 OpenCode / DeepSeek Harness 两个分页；DSH 页支持一个 DSH Remote Hub + 任意数量 SSH 主机。直连 DSH（地址 + 令牌/签名密钥）已从新建入口移除，旧资料仍保留可编辑或删除。
- SSH 主机：支持密码/OpenSSH/PEM 私钥、Host Key 首次核对后固定、远端 `dsh web` 自动探测/启动/复用、稳定本地端口转发、`Host: 127.0.0.1:<远端端口>` 登录 DSH，以及 SSH 断开/远端 dsh 进程重启后的自动恢复。字段、状态目录、错误语义和交互对齐 dsh-Go，实现为 Kotlin/JSch 独立重写。
- DSH Remote Hub 收敛为一个活动账号；Hub 下每台 Host 仍是独立设备/连接，保留多 Host 并行。设备管理页可刷新、退出登录、管理主机和逐台接入。
- 设备分组升级到 v2：升级时旧分组只重置一次并提示；profile、凭据、会话缓存和通知账本不受影响。设备组可同时包含设备（DSH Remote / SSH）与 Harness（OpenCode），并提供「同时连接全部成员」开关。
- 首页默认进入「全部设备」；标题下拉不再把首页切成没有 tab 的单服务器首页，单台设备 drill-down 会显示临时设备胶囊。
- 版本变更：依赖 JSch 0.2.25 与 BouncyCastle 1.79（Android 26–32 的 Ed25519 支持），Release APK 约 6.7 MB。

## 已知限制

- 真机 UI 尚未在 Android 设备上完成端到端验收；SSH 表单、设备管理页和分组编辑需要在真机/模拟器上做一轮交互检查。
- SSH 主机需要 POSIX shell（Linux/macOS/WSL），Windows 原生 OpenSSH 不支持；与 dsh-Go 一致。SSH agent、ProxyJump、2FA OTP 未实现。
- 一个 SSH 主机只管理一个 `dsh web`；远端 dsh 在 App 关闭后仍继续运行。
- DSH Remote Hub 只展示最近的 catalog；旧 catalog 数据保留但不再展示，后续可增加清理入口。
- 通知栏快捷操作在 SSH 主机上受 Android `goAsync` 约 8 秒预算限制，首次连接可能来不及完成，保留通知以便重试。
- 旧版直连 DSH 资料仍可编辑/删除，但不再作为新连接方式；后续版本可评估彻底移除。

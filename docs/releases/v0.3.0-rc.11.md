# Lagoon v0.3.0-rc.11

## 本次更新

- Android 客户端直接请求代码仓库的更新信息并下载版本，不再经过 Lagoon 中枢。
- 用户可选择稳定版或预览版更新通道；只提供更高版本，不会通过切换通道降级。
- 更新请求加入缓存与退避，减少重复访问仓库造成的限流。

## 验证结果

- PR 工作流会验证 Android 更新逻辑和构建；发布工作流在 tag 后重新运行单元测试、构建 release APK，并检查固定签名证书。
- 本文不把发布前的分支检查当作签名发布产物；已签名 APK 以 GitHub Release 的 Actions 结果为准。

## 已知限制

- 当前仍为 rc 预览版本。安装包只能通过发布工作流生成并验证。

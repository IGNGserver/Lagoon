## 已知限制

- 本机未连接真机或模拟器，菜单最后一项与底部选择面板的最终视觉效果需要在手机上确认。
- 默认值只保存在手机本机，不写 Host 配置；电脑端 DSH 的默认预设 / 权限仍在电脑上配置。
- Host 默认权限预设（`permission.defaultPreset`，影响所有客户端）未包含在本版。
- 预发布版本使用与正式版相同的稳定签名；覆盖安装前请确认与已安装版本签名一致。

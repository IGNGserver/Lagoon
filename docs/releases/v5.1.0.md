## 本次更新

- **报错与状态提示体系重构（三级分流）**：
  - 修复同一问题在同屏重复播报：聊天页离线时不再同时出现顶栏副标题、连接横幅、传输子状态、列表顶部提示与输入框提示五处重复文案。
  - 有局部承载容器的操作（发送、新建、删除、重命名、文件浏览与搜索、定时任务、长期目标、排队消息）失败时只在原位置展示错误，不再同时弹出全局红色提示；无承载容器的失败才走全局提示。
  - 新增「信息 / 成功 / 警告 / 错误」四级提示语义：连接已禁用、设备分组保存失败、服务端已读无需同步等提示不再顶着绿色成功对勾弹出。
  - 连接失败与重试统一收敛到一条状态条，SSH 隧道、中继握手等传输子阶段并入同一行说明，不再单独占一行裸露文本。
  - 首次连接握手不再被误判为「实时同步恢复中…」；离线读取缓存时不再显示并不存在的「正在后台重试」。
- **多设备故障透出**：
  - 首页范围胶囊在「全部设备」下显示在线与异常台数。
  - 「选择范围」面板与「设备管理」页对每台连接显示实时状态（在线 / 连接中 / 离线 / 异常）与具体失败原因，异常原因不再被吞掉。
  - 新会话默认值与模型选择在读取失败时明确提示「读取失败」，不再伪装成「服务器没有提供」。
- **组件底座统一**：
  - 全面移除残留的旧版开关、下拉、箭头、动作行与半屏抽屉，统一为自研澎湃组件（卡片、行、开关、下拉、动作行、分段胶囊、半屏抽屉）。
  - 明确区分「向右进入下一级」与「向下展开选择」两种箭头，修正设备管理、添加设备、新会话与聊天页中方向错误的箭头。
  - 半屏抽屉统一为顶部 28dp 连续曲率圆角，消除底部圆角漏出遮罩的问题。
  - 顶栏图标按钮统一为透明底磨砂风格；重绘错误、信息与停止图标，修正「运行中」状态的颜色语义。
- **聊天页减负与阅读排版**：
  - 底部常驻的「设定目标」按钮改为收入「⋯」菜单，仅在已存在长期目标时于底部显示目标条。
  - 后台子会话与命令活动合并进底部运行指示胶囊，点击即可打开后台面板，底部不再层层堆叠。
  - 权限与问答卡片、待处理交互底座统一为澎湃卡片与胶囊样式。
  - Markdown 正文增加段间距，重做标题字号与行高阶梯；代码块增加语言标识、一键复制与语法着色；连续表格行合并进同一横向滚动容器，表头与数据列不再错位；引用块增加左侧强调竖条。
- **动效与导航**：
  - 预测式返回松手后由弹簧连续收尾，消除中途截断与尾帧闪回；返回上一级会话时也能看到底层页面预览。
  - 修复「设置 → 设备管理」返回时直接跳回首页的问题，返回栈现在按进入顺序逐级回退。
  - 列表行与大卡片改为克制的微缩放加表面按压高亮，独立按钮保持弹簧缩放；分段控制器改为带物理弹簧位移的滑动胶囊指示器；分组折叠箭头补齐旋转过渡。

## 本次更新

- **侧滑返回不再闪回**：预见式返回的拖动、松手与回弹改为由同一条转场驱动，松手只是把已经拖出的进度用弹簧补完，不再在两套渲染之间做交接。此前松手那一帧会同时拆掉底层预览、清掉离场页姿态并让目标页以透明首帧进入，于是先闪回手势前的页面再瞬间跳到目标页；现在两页从头到尾由同一个进度摆布。提交与取消的弹簧手感保持不变。
- **设备管理每一级都有整页过渡**：设备详情、整页编辑器、SSH 主机表单改为返回栈上的路由层，与首页进设备共用同一份页面弹簧，进退场不再硬切；DSH 远程中枢从半屏抽屉改为与 OpenCode / SSH 合并的整页编辑器。设备与编辑器层级会随旋转、切换主题保存恢复，侧滑返回逐级预览真实的上一页。
- **子会话与后台改成半屏抽屉**：会话顶栏的「主会话 / 后台活动」分段卡去掉，入口收到 ⋯ 里的「子会话与后台」（底部运行胶囊仍可打开同一个抽屉）。后台活动不再替换正文，点后台命令会先收起抽屉再弹它自己的输出；正文始终在位，滚动位置不再随切换重建。
- **目标与 todo 收成单行胶囊**：目标从整块卡片改为单行胶囊，完整目标、阻塞原因与暂停 / 继续 / 完成 / 清除移入底部面板；新增 todo 胶囊（已完成 / 总数）与任务清单面板，时间线隐藏 `todo_write` 原始工具行。移除了自动续跑的轮次展示——轮次只统计 Host 自动续跑、上限固定 256，旧实现长期停在 0/n。

## 已知限制

- 预见式返回的新转场尚未在真机上复核观感，需要在设备上过一遍：短甩、拖到底松手、拖到中途取消、连划两次、设置里关闭预览后再侧滑。
- 设备详情 / 整页编辑器的退回动画，以及目标与 todo 胶囊在窄屏长文本下的排版，仍需真机确认。
- 本版本为预发布版本，不会标记为 GitHub Latest；需要首页可见的 Latest 标记时，应以正式版类型重新发布。

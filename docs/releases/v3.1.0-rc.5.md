## 本次更新

- 修复网页端自动重载问题：PWA Service Worker 首次安装与后台唤醒时，不再无条件触发 `window.location.reload()`，将刷新控制权收拢至版本更新提示，彻底根除自动刷新导致闪退并弹出全屏品牌与加载动画的缺陷。
- 优化网页端切前台重连机制：实时流（EventSource）在前后台切换时仅在非正常连接状态下执行重连，避免频繁关闭现有流与全量状态重拉。
- 提升会话与服务器视图容错体验：在连接握手与数据同步期间保持当前已渲染的会话内容与服务器信息，取消全屏居中 Spinner 遮罩。
- 优化首页会话列表加载占位条件，已有列表数据时不闪退全列表菊花；输入框草稿在页面隐藏或关闭前即时持久化，防止输入丢失。

## 已知限制

- 自签名证书或 HTTP 环境下无法注册 Web Push 与 Service Worker，需通过 HTTPS 访问中枢开启推送能力。
- 移动端浏览器若未安装为 PWA，后台推送可能受到移动操作系统休眠策略限制。

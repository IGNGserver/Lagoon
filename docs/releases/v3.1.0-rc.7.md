## 本次更新

- Android 和 Lagoon Hub 可以分别注册 DSH Remote 设备，浏览器仍通过 Lagoon Hub 访问。
- 配对时需要登录 DSH Hub、选择 Host，并人工核对 12 位 Host 指纹。
- 会话、历史、消息、取消、权限、提问和文件浏览走 Remote 加密通道；只读响应过大时改为一次分块传输，发送和审批不会因为响应过大而重发。
- 旧的 DSH 直连资料不会自动转换成 Remote。启动令牌、签名密钥、Cookie、草稿和缓存都留在原资料中。

## 验证

- 本地 `:hub:test --tests 'com.igng.lagoon.hub.Remote*Test' --tests 'com.igng.lagoon.hub.HubStoreTest'` 通过。
- 本地 `:app:compileDebugKotlin` 通过。
- 构建在本机 scratch，没有写入项目卷。
- 完整 Android 测试、网页检查和发布签名由 GitHub Actions 执行。

## 已知限制

- 没有可用的 Remote Host，会话、实时流和文件操作尚未做真实互操作验收。
- Android 只完成编译，尚未在真机验证。
- WebRTC、TURN 和独立 Relay 端点不支持。
- Codex、ACP 和 Bot 只探测能力，不作为已支持的后端。
- 旧 DSH 直连入口仍然保留。

## 本次更新

- 修复问答与表单（Question/Form）提交或取消后会话仍卡在“等待你的回答”的问题：收到回答或取消后立即恢复为运行态并更新任务总览，同时记录已处理请求墓碑，避免迟到的对账响应把已回答的问题重新拉回列表。
- 修复后台多服务器概览（`AllServersOverview`）中表单已在电脑端处理后、持久化的“等待回答”状态无法自动清除的问题。
- 修复从系统通知栏直接点击非当前服务器的“允许一次 / 拒绝 / 停止”操作后，后台多服务器概览未能立即结算并刷新状态的问题。
- 修复待处理通知去抖复核权限时若遇到瞬时网络失败，会一并吞掉同会话待回答提问通知的问题。
- 修复本地注册项目未持久化 `sandboxes`（git worktree 目录列表）以及新添加项目缺少 `serverId` 标记的问题：重启应用或离线回退后，worktree 会话仍能正确归属到所属项目，项目选择器中的会话计数保持准确。
- 修复单服务器跨连接返回首页时，`homeProjection` 未同步携带该服务器任务概览（`summary`）的问题。
- 修复服务端返回空 `{}` 或 `{"error":{}}` 时，界面直接弹出 `{}` 的问题，现统一回退为可读的 HTTP 状态说明；增强动态表单对 `default: null`、混合类型默认值、非法正则 `pattern` 与整型 `integer` 字段的兼容与校验。
- 改进会话内「文件」面板与目录浏览器：点开文件预览后提供「← 返回列表」入口，搜索时优先展示搜索结果而不再被已打开的文件预览遮挡；目录浏览器搜索增加请求序号防乱序与搜索状态提示。
- 改进输入框 Agent 与模型选择器：Agent 选择器新增「默认 Agent」选项以支持恢复会话默认配置；模型选择器在顶部展示「最近使用」分组。

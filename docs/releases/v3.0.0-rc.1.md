## 本次更新

- 新增 **Lagoon 中枢**：在任意一台机器上用 docker compose 部署（镜像 `ghcr.io/igngserver/lagoon-hub`，amd64 / arm64），在电脑或手机浏览器里连接、监控和控制各台开发机上的 OpenCode 2.x 与 DeepSeek Harness。中枢常驻监控所有服务器，凭据加密保存在数据卷中；部署说明见 `deploy/README.md`。
- 新增 **网页端**：信息架构与安卓客户端一致（首页服务器胶囊与分组会话列表、对话页、审批与问答、文件 / 改动 / 子任务、模型与 Agent 选择、斜杠命令、图片与文本附件），电脑上是左右分栏，手机上是单页切换。
- 网页可以安装为 **PWA**，并支持 **推送**：任务完成、失败、等待授权或等待回答时推送到每台开启了推送的设备，安卓上可以直接在通知里「允许一次 / 拒绝」。安装与推送需要 HTTPS（反向代理、自带证书或中枢生成的自签名证书）。
- 中枢只有一个访问密码，允许弱密码；登录带不可关闭的失败退避，可在设置里退出所有设备。
- 修复 DeepSeek Harness 新版本把注入给模型的运行环境、时间信息显示成用户消息（安卓端同样修复）。

## 已知限制

- 预览版本。尚未在 iOS 真机主屏 PWA 与安卓 Chrome PWA 上完成推送与键盘的人工验收。
- 中枢不缓存会话历史，每次打开会话从 harness 读取最新一页；更早的消息按需翻页。
- 推送依赖中枢访问浏览器厂商推送服务的外网连接。

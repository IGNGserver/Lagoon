## 已知限制

- 自签名证书或 HTTP 环境下无法注册 Web Push 与 Service Worker，需通过 HTTPS 访问中枢开启推送能力。
- 移动端浏览器若未安装为 PWA，后台推送可能受到移动操作系统休眠策略限制。

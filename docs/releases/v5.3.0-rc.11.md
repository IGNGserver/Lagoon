## 本次更新

- **远程主机配对更容易恢复**：扫码配对中断后可以继续处理，重新登录时区分账号和设备的恢复方式；管理多个中枢时，可直接查看当前设备所属的账号和主机。
- **设备状态与刷新更准确**：明确显示设备离线、登录失效和发现不完整等情况；刷新遇到部分失败时保留尚未重新确认的记录，减少设备或服务突然从列表消失的情况。
- **解绑和退出更清楚**：区分退出账号与移除设备，删除设备时保留其他设备的共享身份；需要联网才能撤销的远端授权会记录并在之后重试。
- **断线后更可靠**：改善远程连接和会话内容的恢复，处理传输超时和消息缺口；审批结果尚未确认时先重新核对，避免重复提交。后台压缩任务也能在重连后继续跟踪。
- **SSH 连接和检测更易用**：支持逐项输入服务器要求的验证码，改进首次信任和指纹变化提示；保存 SSH 设备后可选择检测，并分别展示各项服务的检测结果和失败原因。
- **SSH 连接安全与稳定性**：加强远端服务和本机转发的身份校验，改进连接超时、取消与并发处理，避免配置变化后的旧检测结果覆盖新状态。

## 已知限制

- 本次没有可用的 Android 真机或目标 SSH 主机，扫码、界面操作和跨网络重连仍需在实际设备上验收。
- SSH 模式下的 DSH/OpenCode 服务安全校验需要 Python 3；macOS 主机还需要 `lsof` 和读取进程信息的权限。Windows 原生 cmd/PowerShell 的 SSH 模式尚不支持，可使用 WSL 或其他接入方式。
- 设备离线时，远端授权撤销可能延后；应用会保存待处理状态并在连接恢复后重试。

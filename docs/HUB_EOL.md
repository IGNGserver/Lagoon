# Lagoon 中枢与网页端已停止维护

Lagoon 中枢（`hub/`）与网页端（`web/`）是 v3 的实验性自托管平台。项目已决定只维护 Android 客户端；中枢与网页端不再开发、不再发布镜像、不再提供安全修复或技术支持，相关代码和部署文件已从当前仓库移除。

- **最后一个包含中枢且已打 tag 的版本**：Git tag `v3.1.0-rc.6`。该版本包含「客户端接入/导出」，是唯一仍可作为历史参考的中枢版本；不会再有新的中枢版本。
- **Android 客户端不受影响**：OpenCode 2.x、DeepSeek Harness 直连和 DSH Remote 都继续由 Android 客户端独立维护，不依赖中枢。
- **没有替代的浏览器入口**：中枢下线后，iOS、iPadOS 和桌面浏览器不再有官方客户端。需要移动控制时请使用 Android 客户端。
- **不再提供安全更新**：中枢保存开发机凭据并能触发 shell，停止维护后不应继续暴露在网络上。

## 如果仍有旧部署

当前仓库已移除「从中枢导入」入口。仍在运行旧中枢的部署应立即按以下顺序清理：

1. 在中枢网页中吊销所有「客户端接入」密钥；这些密钥可以导出全部服务器凭据。
2. 停止并删除容器，随后删除 `/data` 数据卷。卷内的 `state.json`、`catalog.json`、`secret.key` 和 TLS 私钥都包含敏感信息。
3. 删除反向代理、Cloudflare Tunnel、Tailscale Serve、端口映射、DNS 记录和监控配置。
4. 如果中枢曾暴露到公网、使用过弱密码或位于不可信网络，轮换 OpenCode Basic Auth 密码和 DSH 凭据，并在 Android 客户端重新配对。
5. 如果安装过中枢的自签名 CA，从各设备的信任存储中移除。
6. 卸载已安装的 PWA，清除浏览器站点数据和 Web Push 订阅。

如果仍需要把旧中枢里的服务器迁移到手机，只能在旧版 Android 客户端（仍带「从中枢导入」的版本）中完成；当前版本不再提供该入口。迁移只包含服务器资料与凭据，不包含任务账本、未读状态、推送订阅或登录会话。
